# 06. 기존 18영웅의 아트·전투 방향

이 표는 **현행 18종·36개 스킬을 새롭게 표현하고 더 적절히 사용하는 방향**이다. 스킬의 실제 ID·해금·계수·쿨타임·상태 종류는 현재 `src/shared/heroes.ts`에서 목록을 추출하여 연결한다. 아래 표현 때문에 새 스킬이나 패시브를 임의로 추가하지 않는다.

## 1. 영웅별 검수 공통 항목

각 영웅은 다음 기록을 가진다: 기본 스프라이트 출처·제작 방식, 8방향 기본 포즈, 걷기, 평타, 두 스킬, 피격, 사망, 학생 확대와 호스트 전체맵 캡처, 공격 준비·발사·적중 타이밍 로그.

동일 캐릭터가 다른 방향에서 머리 크기·눈 위치·장비 위치가 변하지 않는지 검사한다. 좌우 mirror로 처리한 방향과 별도 작성 방향을 명시한다. 무기의 손잡이와 발사점이 실제로 연결되어야 한다.

## 2. 특정 조합 회귀

성전사+궁수+사제는 전열·후열·지원의 기본 검증 조합이다. 야만인+화염술사는 광역기 중첩 가독성, 암살자 대 사제+수도승은 후열 진입·보호, 얼음술사 다수는 상태 제한, 전설3종 혼합은 이펙트 과밀과 역할 경계 검증에 사용한다.

수치가 높은 희귀 영웅만 항상 최고 선택이 되지 않는지 현행 밸런스와 비교한다. 다만 이번 아트 리워크 명분으로 등급 효과나 영웅 수치를 임의로 평준화하지 않는다. 변경은 별도의 밸런스 로그와 재현 시험으로 남긴다.
