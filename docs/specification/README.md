# 클래스 클래시 Codex 개발 명세 v1.0

작성 기준: 2026년 10월 26일, 한국 시간. 개발 대상 저장소: https://github.com/YEOMT/Classclash.git

이 묶음은 Codex가 실제 플레이 가능한 첫 버전을 구현하기 위한 요구사항, 전투 알고리즘, 데이터 규격, 아트 기준, 검증 절차다. 게임 소스나 테스트 완료 보고서가 아니다. 사용자는 제작을 Codex에서 진행하기로 했다. 이번 명세 작성 과정에서는 원격 저장소를 변경하지 않았다.

## 사용하는 방법

1. Codex에서 YEOMT/Classclash를 작업 저장소로 연다.
2. 이 ZIP의 docs/specification 내용을 저장소의 docs/specification에 넣는다. 처음부터 존재하는 코드나 AGENTS.md가 있으면 먼저 읽는다.
3. 00_CODEX_START_PROMPT.md의 본문을 작업 지시로 전달한다.
4. Codex는 문서를 읽고 설계 요약만 반환하지 말고, 로컬 실행·실제 전투·멀티플레이·AI 시험·검증 보고서까지 구현한다.
5. 배포 자격 증명이 없더라도 로컬 개발과 자동시험은 완료한다. 공개 배포는 별도 권한과 실행 환경을 확인한다.

## 우선순위

최신 사용자 지시가 최우선이다. 문서 안에서는 01의 명시적 사용자 확정 규칙을 우선한다. 전투 판정은 02, 개별 영웅 수치는 03, 서버 자료·권한은 04, 시험 통과 조건은 05가 해당 영역의 기준이다. balance.defaults.json은 공통 상수만 담는다. 수치가 어긋나면 임의로 한쪽을 숨기지 말고 문서와 설정을 함께 정합화한다.

문서의 초기 수치는 구현 가능한 출발점이다. 이미 사용자에게 승인된 밸런스라는 뜻이 아니다. Codex는 구조와 사용자 규칙을 보존하면서 실제 시험으로 수치만 조정하고 변경 근거를 기록한다. 플레이 가능한 첫 버전의 필수 기능을 나중으로 미루거나, 동그라미 이동 데모를 완성 게임으로 제출하지 않는다.

## 명확히 분리할 상태

- 명세 완료: 이 묶음의 현재 상태.
- 코드 구현 완료: Codex가 구현 후 입증해야 하는 상태.
- 로컬 멀티플레이 검증: 서버와 여러 독립 클라이언트로 검증한 상태.
- 학교 30개 실기기 검증: 별도 실제 시험이 필요한 상태.
- 공개 배포 완료: 실제 접속 주소와 서버 운영을 확인한 상태.

실행되지 않은 시험을 통과로 적지 않는다. AI 학생 30명 시험은 서버 전투 부하를 검증하며, 독립 브라우저 30개 또는 실제 학생 기기 30개의 렌더링·통신 검증을 대신하지 않는다.
