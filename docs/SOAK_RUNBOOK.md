# 30 STANDARD AI 분포 실행과 재개

실제 권위 서버와 같은 룸·퀴즈·경제·전투 코드를 고정20Hz로 빠르게 진행한다. 렌더를 재생하거나 자원·피해·승패를 주입하지 않는다. 이 실행은 브라우저 FPS 또는 동시30명 네트워크 부하 측정과 별개다.

## 새40경기 시작

저장소 루트에서 의존성을 설치한 뒤 실행한다. 명령의 배치 이름은 새 이름으로 정한다. 기존 결과 폴더를 삭제하거나 덮어쓰지 않는다.

    node scripts/soak-final.mjs --stage=prepare --batch=my-standard40 --fresh=1
    node scripts/soak-final.mjs --stage=all --batch=my-standard40 --workers=3

prepare는 코드/설정의 SHA-256과 원래 수치를 저장할 뿐 경기를 시작하지 않는다. all은 시드1001–1040의40경기를 최대3개 작업자로 실행한다. 각 경기의 시작 퀴즈20개·초기 정비·준비·출정과 전투 퀴즈·정비·실제 넥서스 파괴를 같은 구현으로 진행한다. 각 경기의 관측 상한900초는 **시험 종료 상한**이며 게임의 승리 규칙이 아니다. 그 안에 끝나지 않으면 미완료/FAIL로 남긴다.

파일은 artifacts/배치이름/manifest.json, seeds/seed-번호.json, combined-results.json, summary.json에 남는다. 작업자별 .log는100초 간격의 실제 경기 진행과 벽시계 소요를 보여 준다. 완료한 시드 파일은 원자적으로 기록하며 중단 중이던 부분 경기는 완료 표본으로 세지 않는다.

## 중단 후 이어가기와 결과만 읽기

같은 all 명령을 다시 실행하면 이미 끝난 시드를 건너뛰고 나머지만 진행한다. 코드나 balance를 바꿨다면 기존 결과와 섞지 않고 새 배치 이름으로 prepare부터 시작한다. 작업자는 매 경기 전후 지문을 검증한다.

    node scripts/soak-final.mjs --stage=report --batch=my-standard40

report는 경기 없이 기존 파일만 합산한다. 과거 코드의 증거도 읽을 수 있다. 화면상 사전 분포가 나쁘더라도 all은 전체40개를 측정하며, 10개만의 결과를40개로 확대하지 않는다. 필요할 때 screen은 앞10개, final은 남은30개를 명시적으로 실행할 수 있고 사전10개 실패가 나머지 실행을 막지는 않는다.

artifacts/soak.pause 파일이 있으면 현재 경기를 마친 뒤 다음 경기 전에 대기한다. 해당 파일을 제거하면 계속된다. 브라우저의 성능을 단독 측정할 때에는 소크 작업자들을 함께 실행하지 않는다.

## 판정

모두 만족해야 PASS, 미달하면 종료코드1과 FAIL이다. 중단/준비 상태는 INCOMPLETE이며 PASS로 세지 않는다.

- 서로 다른 시드40개, 실제 넥서스 파괴로40개 모두 완료.
- 600–780초 구간28개 이상, 완료 경기 시간의 중앙값600–780초. 중앙값은 짝수 표본의 두 중앙값 평균이다.
- 음수 자원·플레이어의 중복 활성 영웅·불법 위치·5초 이동 정체·봇 정체 없음.
- 경기 경과초×20과 실행 틱 수 일치. 시작 웨이브+20초별 웨이브 수 및 웨이브당28기 생성 일치.
- 완료 경기마다 실제 NEXUS 파괴 기록과7개 시상 항목 존재.

보고서에는 첫 외부/내부/수호 타워 파괴, 수호 타워 접근, 넥서스 첫 피해, 평균 생존 유닛 수, 전설 획득, 사망, 완료 정비 대기, 종료 때 아직 정비 중인 수, 정체를 함께 남긴다. 여러 작업자와 개발 PC의 다른 작업은 벽시계·틱 처리시간에 영향을 주므로 이를 학생 기기의 실제 FPS로 보고하지 않는다.
